## Claim

Heterogeneous corpora (PDFs + structured tables + code) degrade embedding quality more than structural link quality — meaning graph traversal outperforms semantic search on cross-type queries.

## Operationalization

Dataset: mixed corpus with equal parts PDF paragraphs, table cells, and code blocks (100K blocks each).
Metric: recall@10 for cross-type queries (e.g., a natural-language question answered by a table row).
Baseline: pure semantic ANN search.
Intervention: 2-hop graph traversal from the best ANN hit.
Acceptance criterion: graph-expanded results improve recall@10 by > 15% vs. ANN alone on cross-type query set.

## Null Hypothesis

Embedding quality degrades uniformly across content types; graph traversal provides no additional recall benefit for cross-type queries.

## Experiment Spec

1. Build a 300K-block mixed corpus (100K each: PDF paragraphs, table cells, code blocks).
2. Embed all blocks with text-embedding-3-small.
3. Construct structural links (section containment) and AI links (Claude-classified semantic relationships) across types.
4. Build a 200-question cross-type eval set: questions whose ground-truth answer block is a different type than the question.
5. Evaluate: (a) ANN top-10 recall, (b) ANN top-10 + 2-hop graph expansion recall.
6. Compare recall@10 delta.
