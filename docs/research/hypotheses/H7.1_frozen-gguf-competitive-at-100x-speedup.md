## Claim

A student model distilled from a graph-derived curriculum and exported to GGUF achieves within 10% task accuracy of the graph-resident inference client on the same benchmark, at 100x lower inference latency — making frozen export the preferred deployment path for latency-sensitive workloads.

## Operationalization

Dataset: legal corpus (10K contracts), 3 task benchmarks (clause extraction, contradiction detection, citation tracing).
Metric: task accuracy delta (frozen GGUF vs. graph-resident client); inference latency ratio.
Baseline: graph-resident inference client (Area 3).
Intervention: student model distilled from graph curriculum (Area 2 BFS walk), quantized to int8, exported to GGUF. Run via llama.cpp.
Acceptance criterion: accuracy within 10% of graph-resident client AND latency at least 100x lower.

## Null Hypothesis

The distillation process loses too much of the graph's relational structure; the frozen model falls more than 10% below graph-resident accuracy, meaning the trade-off is unacceptable for any latency-sensitive workload.

## Experiment Spec

1. Generate graph-derived curriculum using BFS walk from Area 2 (10K contracts, ai + structural links).
2. Fine-tune a base LM (e.g., Llama-3.2-1B or similar small model) on the curriculum.
3. Quantize to int8 using llama.cpp quantization toolchain. Export to GGUF.
4. Evaluate both graph-resident client and frozen GGUF on 3 benchmarks. Record accuracy and latency P50/P99.
5. Compute accuracy delta and latency ratio.
